## 0. 产品怎么拆（范围纪律）

| 范围 | 为谁 | 本计划态度 |
|------|------|------------|
| **R1 上海银行** | 普/沪识别与播报、可打断通话、一句话复刻；对话由**行方引擎**提供 | **合同主航道**；验收与排期优先 |
| **R2 海南** | 文昌混说识别（DL-17）+ 海南话发音人（TTS-28）；复用同一管理平台 | **可并行探路**；正式验收等 HN-Q + 语料 |
| **DP 对话平台** | 内置流程/知识/电话/运营 | **独立排期**；上海交付**不含**内置对话 |

```
终端/SDK → 统一网关 → ASR →（行方对话）→ TTS/复刻
              ↑ L1 asr-tts/voice-platform
              ↓ Engine SPI（平台只认此协议）
            L0：mock / 云 / voice-engine（Qwen3-ASR · CosyVoice3）
```

**PM 硬指标（口径待 SH-Q / HN-Q 冻结）**

| 对象 | 目标 | 归属 |
|------|------|------|
| R1 沪语识别 | 标品 ≥80%，业务 ≥95%，老年单列 | ASR |
| R1 时延与听感 | 首字 ≤400ms，首包 ≤700ms；拟人度+MOS >8.5 | ASR/TTS |
| R1 端侧与容量 | 三端真机；并发 ≥50、7×24 | 移动+运维 |
| R2 识别 | 字准 ≥85%（内部暂定，普/琼分组） | **DL-17，非 TTS** |
| R2 合成 | MOS ≥4.0（内部暂定，母语评分） | **TTS-28** |

## 3. 执行波次（优化后）

### 波次 A — 本机可跑闭环 ✅ 基本完成

剩余：进程常驻脚本化；A3/A4 真声。

### 波次 B — R1 非移动可验收（约 2～4 周，主航道）

| 主题 | 锚点 | 出口 |
|------|------|------|
| B1 金融听感与沪语 | TTS-24/29/34，ASR-12/36/38 | 听评表 + 规则回归 |
| B2 ASR 资源闭环 | ASR-21～24，MGT-* | 热词/LM 平滑生效 |
| B3 复刻合规 | VC-11～13 | 授权→销毁 |
| B4 行内同步 | GW-15，OPS | 对账可定位 |
| B5 容量时延 | ASR-37，TTS-30 | P95 + ≥50 路 |
| B6 发布回退 | OPS-07，WP-28 | 演练记录 |

本波不做：三端 SDK、海南正式包、DP 全量。

### 波次 C — 移动 R1（1.1.0）

MOB 全链路；可与 B5/B6 部分并行，不挡非移动签字项（除合同强制真机条款）。

### 波次 D — R2 海南（探路并行，验收独立）

| 阶段 | 内容 | 说明 |
|------|------|------|
| **D0 = W0–W2** | 目录/转 wav、Cosy 零样本听感三选一 | **当前可开**；不上 SPI 也能研 |
| W3 | presets + **先扩 `min-hainan` 白名单** + SPI | 依赖 W2≥可演示 |
| W4 | 文昌金融前端/词典 | 与扩数据并行 |
| W5 | 授权扩录；不足再评估微调 | 正式 MOS 门槛 |
| D1～D4 | DL-17、评测、发布、客户验收 | TTS 稳定后再抢语料 |

路线：文昌 = zero-shot + instruct/前端；**微调不是默认第一步**。

### 波次 E — DP（可选）

DP-Q 通过后：`TURN` → `DLG` → `MED` → `IND` → `DOP`。

## 5. 本周怎么排（评审后默认）

与「先摸 Cosy、接口清楚后再谈微调」一致：

| 优先级 | 做什么 | 为什么 |

| **不做** | 文昌 LoRA/SFT、DL-17 硬训、把海南算进上海交付 | 条件不成熟 / 范围纪律 |

## 6. 风险与纪律

| 风险 | 对策 |
|------|------|
| DP/海南混进上海交付 | 清单分栏；验收账本隔离 |
| 3 条文昌报 MOS/发音人交付 | 仅 W2 POC；正式走 W5 |
| 字准与 MOS 指标混用 | 字准→DL-17；MOS→TTS-28 |
| 有接口无听评报达标 | 必须人工量表 + 冻结集 |
| 密钥进仓 | `.runtime/keys`、apiKey 永不提交 |
| GPU 争用 | `gpu_lock`；联调前 `nvidia-smi` |
