## 1. 一句话说清楚你要交付什么

客户最终要的是一整套「能听会说」的智能语音对话平台。你负责其中的 **「说」**：

> 业务侧（或对话引擎）给你一段 **普通话书面中文**，  
> 你把它合成成 **听起来像文昌话、能听懂内容** 的语音播报。

产品编号叫 **TTS-28**（海南话发音人）。  
银行柜面场景优先（会议倾向）；高校场景还没最终定，话术先按银行准备。

**本阶段（进海南实地前）不要求**：合同级 MOS≥4.0、正式发音人交付、平台训练中心真训。  
**本阶段要求**：固定几十句银行短句上，能稳定合成、听感「像样」，并留下可复听证据。

## 2. 先建立三个正确预期

### 2.1 你熟悉的「接口」和「微调」是两件事

| | 接口 / 推理（你擅长） | 微调 / 训练（后置可选） |
|--|----------------------|------------------------|
| 在干什么 | 调已有模型：给文本 → 出语音 | 用很多录音改模型权重 |
| 现在仓库里 | Cosy 基座、`cosy-lab`、SPI 引擎都齐 | Cosy 文昌 **还没真训过** |
| 本周要不要碰 | **要，主战场** | **不要**，除非听感结论明确要求 |

### 2.2 为什么选 Cosy，不选千问 TTS

会议结论：文昌话属闽南语系分支；**CosyVoice 训练数据里有闽南相关先验**，千问 TTS 几乎没有。  
仓库已按此选型：`Fun-CosyVoice3-0.5B-2512` + conda `tts`。  
105 上以前做过的 Qwen3-TTS LoRA 只是历史对照，**不能当成文昌 Cosy 已经训好了**。

### 2.3 验证为什么难（提前心里有数）

团队听不懂文昌话 → 听感很主观。会议共识：

1. **母语听感**（最好有本地人复述）——证「地道不像」  
2. **ASR 回测**（合成音再识别回原文）——只能证「清不清晰」，不能证「地道」  
3. 正式 **MOS** ——合同阶段再上，本周不做满分验收  

先把「能合成 + 可复听 + 有文字结论」做扎实，比急着开训有用。

### 阶段 1 · 零样本听感 POC（当前主战场）

目标：在 **不上 SPI、不开训** 的前提下，搞清楚 Cosy + 文昌参考音 **能不能说出像样的文昌话**。

#### 1.1 评测句准备

| 编号 | 任务 | 优先级 | 状态 | 做什么 | 完成标准 |
|------|------|--------|------|--------|----------|
| T1.1 | 冻结评测句清单 | P0 | 待做 | 银行柜面：迎客/安全/结束 + 金额/日期/手机号/卡号各若干；总计建议 **30～50 句**，先冒烟可用 **15 句** | 落到 `dialect-assets/wenchang/evals/sentences.md`（或 csv） |
| T1.2 | 听感记录表模板 | P0 | 待做 | 四维：像说话人 / 像文昌 / 可懂 / 读法怪点；每句 1～5 分 + 一句话备注 | 模板文件可填；每组合成对应一行 |

#### 1.2 对照实验（W2 五组）

用 `cosy-lab`（`./cosy-lab/run.sh` → http://127.0.0.1:7865）。  
每组：**先 5 句冒烟，再扩到 ≥10 句**（时间紧可先 5）。

| 编号 | 组别 | 设置 | 优先级 | 状态 | 目的 | 完成标准 |
|------|------|------|--------|------|------|----------|

| T1.4 | B | 文昌 ref + instruct「海南文昌话」 | P0 | 有样音，听感表未齐 | 口音像不像文昌 | 补听感表 |
| T1.5 | C | 文昌 ref + instruct「闽南语」 | P0 | 待做 | 大类先验对照（**不能当达标**） | 与 B 分开记结论 |
| T1.6 | D | 普通话 ref + 同上 instruct | P1 | 待做 | 没有文昌音色时，指令够不够 | wav + 结论 |
| T1.7 | E | 文昌 ref + 金融句 | P0 | 待做 | 数字/金额读法怪不怪 | 单列「读法」问题 |

### 阶段 2 · 接入平台引擎（听感够用之后）

目标：从「调试台能播」变成「平台 SPI / 演示端能播」。

## 6. 日常怎么干活（操作手册级）

### 6.1 每天开工

```bash
conda activate tts
cd /home/apc/xny/dialect-speech-platform
./cosy-lab/run.sh
# 浏览器 http://127.0.0.1:7865
```

- 合成结果在：`dialect-assets/wenchang/evals/`  
- 若与现役 `voice-engine` TTS 抢 GPU：先停现役 worker，或错开时段  

### 6.2 每合成一组就记什么

不要只存 wav。至少同步记下：

1. 组别（A/B/C…）  
2. 模式（zero_shot / instruct2）  
3. instruct 原文  
4. 参考音路径  
5. 输入文本  
6. 四维分数 + 一句话  

否则两周后自己也听不出「哪次好」。

### 6.3 和别的角色怎么交界面

| 你给他们 | 他们给你 |
|----------|----------|
| 推荐的 Cosy 配置 / presets 草案 | 场景确认（银行/高校） |
| 录音规格 + 朗读文本清单 | 高校/众包语料、母语听评 |
| SPI 冒烟通过说明 / 权重路径 | 平台挂节点、演示页联调 |
| 听感结论与风险（主观性） | 合同分阶段验收口径 |

## 7. 风险清单（开发时盯住）

| 风险 | 影响 | 你怎么处理 |
|------|------|------------|
| 只有 3 条参考音 | 音色不稳、不够训 | POC 用零样本；并行要扩录 |
| 文件名≠真实口播 | zero-shot 对不齐 | prompt 标「待校」；有母语再改 |
| 把「闽南 instruct」当文昌达标 | 验收口径跑偏 | 组 C 只作对照，结论分开写 |
| 听不懂方言却自我感觉良好 | 交付扯皮 | 强制留 wav + 文字；尽量找母语复述 |
| 白手套沟通慢 | 语料/正音拖延 | 自建兜底语料；不阻塞阶段 1 |
| 过早开训 | 浪费算力、无结论 | 过阶段 1 门槛；见阶段 3 |
| 密钥进仓库 | 安全事故 | 只放 `private/`，不提交 CSV |
